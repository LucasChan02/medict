# Embedded Breeze icons

The SVG files in this directory come from
[KDE Breeze Icons](https://invent.kde.org/frameworks/breeze-icons), tag
`v6.31.0`.

The icon files use the GNU Lesser General Public License, version 2.1 or
later. See `LICENSE-LGPL-2.1.txt`.

Medict embeds a small subset as a fallback for platforms that do not provide
the Plasma Breeze icon theme. A Plasma desktop uses the installed system icon
theme first.
